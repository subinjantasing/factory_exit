# Factory Exit Screening System
ระบบตรวจคัดกรองและสุ่มตรวจพนักงานเมื่อออกจากโรงงาน

## 📋 คุณสมบัติ
- 🔐 ระบบเข้าสู่ระบบแยกสิทธิ์: ผู้ดูแลระบบ (Admin) และเจ้าหน้าที่รักษาความปลอดภัย (Guard)
- 🔑 รหัสผ่านเข้ารหัสแบบ Hash ด้วย `password_hash()`
- 📱 รองรับหน้าจอมือถือและคอมพิวเตอร์
- 🎨 ออกแบบสวยงาม ใช้งานง่าย
- 🚪 บันทึกและสุ่มตรวจพนักงานแบบสุ่ม

## 🛠 เทคโนโลยีที่ใช้
- PHP 7.0+ (PDO)
- MySQL
- HTML5 + CSS3
- Font Awesome
- Google Fonts (Sarabun)
